The Google Apps Script companion requires deploying `scripts/google-apps-script.js` from the repo root into a Google Apps Script project named "GitLab MR Forwarder", configuring `WEBHOOK_URL` and `GMAIL_LABEL`, and setting a time-driven trigger on `processNewEmails` running every minute; testing involves marking an old GitLab MR email as unread, applying the configured label, then starting the local server with `npm start`.
