This module is a documentation-only leaf containing four Markdown artifacts that describe the Argos project: `Argos_PRD.md` (product requirements document with functional/non-functional requirements, MVP scope, and acceptance criteria), `Argos_Build_Prompt.md`, `Argos_Idea.md`, and `Google_Apps_Script_Setup.md` (step-by-step guide to deploy the Gmail-to-local-webhook bridge via Google Apps Script). There is no executable code; it serves as the human-readable spec and deployment reference for the sibling implementation.
