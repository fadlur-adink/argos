The repository is a flat pnpm workspace (pnpm-workspace.yaml) with a single top-level package.json declaring the `argos` application; there are no workspace packages listed, so the children live as sibling directories rather than being npm-published units. The root tsconfig.json pins the TS build target (es2022, commonjs, strict) and entry point (`src/index.ts`) for the service child, while sqlite3 native builds are explicitly allowed via `allowBuilds`. Cross-child wiring is minimal: the service child consumes shared runtime configuration from `scripts_and_config`, and both the service and the Google Apps Script bridge in `scripts_and_config` communicate over HTTP against the same webhook contract documented in `docs`.
