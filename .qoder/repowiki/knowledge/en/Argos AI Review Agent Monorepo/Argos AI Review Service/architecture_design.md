Single-process Node/TypeScript application bootstrapped from `src/index.ts` in a fixed startup sequence: load+validate config (`config.ts` via Zod), init SQLite DB (`db.ts`), verify GitLab CLI auth (`gitlab.ts`), clean orphaned worktrees (`git.ts`), then wire an in-process `EventQueue` (FIFO, single-processor via `setImmediate`) to an HTTP server built on Express (`server.ts`). The server exposes `/webhook` (GitLab email payload → parsed by `parser.ts` into `MergeRequestEvent`), `/api/reviews`, `/api/reviews/:id`, `/api/reviews/:id/retry`, and serves static UI under `public/`. Each queued event follows a pipeline: fetch MR details/diff via `gitlab.ts`, create an isolated git worktree via `git.ts`, invoke the external `agy` CLI through `child_process.spawn` inside `engine.ts` (with a 20-minute timeout and retry wrapper from `retry.ts`), persist the markdown report under `state/reviews/<project>/`, update DB status, and fan out notifications through `telegram.ts`, `email.ts`, and `notifier.ts`. Dependency direction is one-way: `index.ts` orchestrates; `server.ts` depends on `queue`/`parser`/`db`; `engine.ts` depends on `gitlab`/`retry`; notification modules depend only on `config`/`logger`.
